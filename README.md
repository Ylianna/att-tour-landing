# Тестовое задание

Адаптивная верстка одностраничного сайта в соответствии с дизайн-макетом Figma.

## 🔗 Ссылки на проект
- **Репозиторий:** https://github.com/Ylianna/att-tour-landing
- **Живой сайт (Vercel):** https://att-tour-landing.vercel.app

## 🛠 Технологический стек
- HTML5 (семантическая разметка)
- SCSS (архитектура стилей, переменные, медиа-запросы)
- Нативный JavaScript (ES6+)
- **Vite** (сборщик проекта)
- **Flatpickr** (библиотека интерактивного календаря)

## 🚀 Особенности реализации
- Полный адаптив под mobile (от 360px), tablet (от 768px) и desktop (от 1024px).
- Интерактивное мобильное бургер-меню (плавное раскрытие шторки).
- Плавный скролл к блоку расписания при клике на кнопку.
- Кастомный слайдер отзывов (адаптирован: 2 карточки на desktop, 1 на mobile).
- Форма фильтрации карточек расписания по типу экскурсии на чистом JS.
- Строгое соблюдение методологии БЭМ.

## 💻 Инструкция по локальному запуску

1. Клонируйте репозиторий:
```bash
git clone https://github.com
```

2. Перейдите в папку проекта:
```bash
cd название-папки
```

3. Установите зависимости:
```bash
npm install
```

4. Запустите локальный сервер для разработки:
```bash
npm run dev
```
Проект откроется локально по адресу `http://localhost:5173/`.
